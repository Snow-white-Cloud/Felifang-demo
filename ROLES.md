# Роли 
Мы выделили несколько ролей, необходимых команде для функционирования и развития проекта. Ниже даны их описания, требования и выгоды, которые Вы получите, присоединившись к нам. 

Не рассматривайтесь и не опускайте руки, если ничего не подошло! Мы и сами могли что-то упустить из виду. Откликайтесь, ведь, возможно, Возможно, именно Ваши идеи и Ваша искра помогут проекту задышать свободнее.

О правилах вступления описано [здесь](./CONSTITUTION.md#4-как-присоединиться).

## Описания

### Дизайнер (UI/UX + 2D-художник)
Цель: Сделать платформу визуально приятной, целостной и удобной для игроков, чтобы они хотели в неё возвращаться.

Задачи:
- разработать дизайн интерфейса (экраны входа, лента постов, чаты, профиль, настройки; после -> игровое поле, предметы, инвентарь и т.д.);
- создать концепты и финальные арты для интерфейса, аватарок, иконок.
- подготовить макеты для фронтенд-разработчиков (Figma / Photoshop);
- адаптировать дизайн под веб-версию (браузер).

Требования:
- базовое владение Figma или Photoshop;
- понимание принципов UI/UX (или готовность обучаться);
- портфолио (пусть маленькое, но чтобы можно было оценить стиль);
- усидчивость и любовь к деталям;
- знание основ дизайна для социальных платформ (будет плюсом).

Что Вы получите:
- реальный проект в портфолио: дизайн интерфейса для социальной платформы, а позже и для браузерной игры;
- опыт работы в команде с разработчиками и геймдизайнерами;
- возможность научиться адаптировать дизайн под технические ограничения;
- готовый кейс для резюме: «Разработал(-а) UI/UX для экосистемы из браузерной соцсети и игры»;
- а ещё: Вы станете частью команды, которая строит экосистему с нуля. Это не просто «задачи» -- это возможность влиять на продукт и учиться в спокойной и дружелюбной обстановке.

### Frontend-разработчик (React + TypeScript, в будущем PixiJS)
Цель: Разработать клиентскую часть социальной платформы, которая будет отдельным сервисом, взаимодействующим с бэкендом.

Задачи:
- разработать интерфейс на React (лента постов, чаты, профиль, настройки, уведомления);
- подключить WebSocket для получения обновлений в реальном времени (чаты, уведомления);
- подружить интерфейс с бэкенд-API (REST + WebSocket);
- реализовать адаптивность под разные экраны (десктоп, планшет, телефон);
- (в будущем) освоить PixiJS и интегрировать его для отображения игрового мира (карта, персонажи) — это отличная возможность пополнить портфолио опытом работы с игровой графикой. Сейчас фокус — на соцсети.

Требования:
- базовое знание TypeScript и React (или готовность изучить).
- готовность разобраться с PixiJS;
- понимание работы с API и WebSocket (или готовность изучить);
- внимание к деталям интерфейса.

Что Вы получите:
- опыт разработки отдельного фронтенд-сервиса для социальной платформы;
- навыки интеграции React, TypeScript и WebSocket;
- понимание работы с микросервисной архитектурой (фронт как отдельный сервис);
- готовый кейс для резюме: «Разработал(-а) фронтенд-сервис для соцсети с живыми чатами и уведомлениями»;
- а ещё: Вы станете частью команды, которая строит экосистему с нуля. Это не просто «задачи» -- это возможность влиять на продукт и учиться в спокойной и дружелюбной обстановке.

### Backend-разработчик (Go)
Цель: Ускорить разработку бэкенд-части: микросервисов авторизации и соц.сети. 

Задачи:
- писать код на Go для микросервисов;
- разрабатывать API для фронтенда (REST + WebSocket);
- участвовать в проектировании архитектуры новых фич;
- писать тесты и документацию;
- (по возможности) настраивать взаимодействие с PostgreSQL, Redis.

Требования:
- базовое знание Go (уровень «знаю основной синтаксис, интерфейсы, структуры»);
- готовность разобраться с Docker и микросервисами;
- желание учиться и перенимать опыт от наставника, если потребуется.
- усидчивость и умение искать информацию.
- (желательно) понимание работы с БД (SQL).

Что Вы получите:
- реальный микросервисный проект на Go с JWT, JWKS и асимметричным шифрованием;
- опыт работы с PostgreSQL, Redis и Docker;
- навыки проектирования REST API, WebSocket, gRPC и архитектуры;
- готовый кейс для резюме: «Разработал(-а) микросервисы авторизации и соцсети для онлайн-платформы, проводил(-а) тестирование»;
- а ещё: Вы станете частью команды, которая строит экосистему с нуля. Это не просто «задачи» -- это возможность влиять на продукт и учиться в спокойной и дружелюбной обстановке.

### Инженер баз данных (Database Engineer)
Цель: доработать схемы базы данных для микросервисов авторизации, игры и соц.сети, оптимизировать запросы и написать слой `storage` на Go для взаимодействия с БД.

Задачи:
- проектирование схем БД (PostgreSQL, Redis);
- оптимизация запросов, создание индексов и настройка производительности;
- написание слоя `storage` на Go (структуры для работы с БД, транзакции, пулы соединений);
- настройка и поддержка бэкапов;
- помощь в миграции данных при изменении схем.

Требования:
- знание SQL на уровне «могу написать сложный запрос с JOIN»;
- понимание принципов работы индексов и транзакций;
- базовое знание Go (или готовность его освоить);
- внимание к деталям и усидчивость;
- желание разобраться в архитектуре распределённых систем.

Что Вы получите:
- опыт проектирования БД для микросервисной архитектуры;
- навыки работы с Redis и оптимизации запросов;
- готовый кейс для резюме: «Спроектировал(-а) и реализовал(-а) слой хранения для соцсети с авторизацией»;
- а ещё: Вы станете частью команды, которая строит экосистему с нуля. Это не просто «задачи» -- это возможность влиять на продукт и учиться в спокойной и дружелюбной обстановке.

### Тестировщик
Цель: обеспечить стабильную работу микросервисов и покрытие кода тестами.

Задачи:
- ручное тестирование новых фич (регистрация, вход, лента постов, чаты);
- описывать баги в удобном формате (Issue на GitHub);
- составлять тест-кейсы для основных сценариев;
- постепенно внедрять автоматические тесты (на Python или Go);
- проверять, что после обновлений ничего не сломалось.

Требования:
- внимательность и усидчивость;
- умение чётко описывать проблемы;
- базовое понимание, как работают веб-приложения;
- готовность учиться автоматизации;
- базовое знание Python или Go.

Что Вы получите:
- опыт тестирования социальной платформы с микросервисной архитектурой;
- навыки написания тест-кейсов и работы с баг-трекингом;
- возможность освоить автоматизацию на реальном проекте;
- готовый кейс для резюме: «Обеспечил(-а) стабильность микросервисов авторизации и соцсети через ручное и автоматизированное тестирование»;
- а ещё: Вы станете частью команды, которая строит экосистему с нуля. Это не просто «задачи» -- это возможность влиять на продукт и учиться в спокойной и дружелюбной обстановке.
