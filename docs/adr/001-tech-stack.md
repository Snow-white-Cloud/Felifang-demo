# ADR-001: Выбор технологического стека

**Дата:** 17.03.2026  
**Статус:** Реализовано  
**Автор:** Snow-white-Cloud

## Контекст

Проект представляет собой **микросервисы**, которые должны взаимодействовать между собой по gRPC, работать с базами данных, обрабатывать HTTP-запросы, поддерживать WebSocket-соединения для чатов и игровой логики.

Необходимо выбрать технологии, которые обеспечат:
- высокую производительность;
- удобство разработки;
- масштабируемость;
- безопасность.

## Решение

| Компонент | Выбор | Обоснование |
| :--- | :--- | :--- |
| **Язык бэкенда** | Go 1.26.4 | Встроенная конкурентность, быстрая компиляция, простота, активное сообщество |
| **API-протокол** | REST (основной) + WebSocket (чат/игра) | REST простой, понятный, кешируемый; WebSocket для real-time |
| **База данных** | PostgreSQL 15 | ACID, индексы, JSONB, надёжность, поддержка транзакций |
| **Кеш / сессии** | Redis | In-memory, TTL, Pub/Sub, быстрый |
| **Контейнеризация** | Docker + Docker Compose | Воспроизводимость, изоляция, локальная разработка |
| **Микросервисное общение** | gRPC (внутреннее) + REST (внешнее) | gRPC — быстрый, контрактный; REST — для внешних клиентов |
| **HTTP-роутер** | chi | Лёгкий, совместим со стандартным `http.Handler`, группировка маршрутов |
| **JWT** | `golang-jwt/jwt/v5` | Стандарт, поддержка RS256, активная поддержка |
| **Логирование** | `slog` | Структурированное логирование, встроен в Go 1.21+ |
| **Валидация** | `go-playground/validator` | Декларативная валидация через теги |
| **Миграции БД** | `golang-migrate/migrate` | Контроль версий схемы, поддержка PostgreSQL |

## Сравнение с аналогами

| Компонент | Альтернатива | Почему не выбрано |
| :--- | :--- | :--- |
| **Язык** | Python / Node.js | Go быстрее, лучше конкурентность, меньше потребление памяти |
| **API-протокол** | Только gRPC для внешнего API | Браузеры плохо поддерживают gRPC без grpc-web, сложнее отладка |
| **База данных** | MySQL / MongoDB | PostgreSQL лучше для сложных запросов и транзакций; MongoDB — нет ACID |
| **Кеш** | Memcached | Redis богаче функциональностью (Pub/Sub, структуры данных) |
| **HTTP-роутер** | `gorilla/mux` | Устаревший, поддержка прекращена, тяжеловесный |
| **Логирование** | `logrus` / `zap` | `slog` встроен в Go, меньше зависимостей |
| **Миграции** | `goose` | `golang-migrate` более популярен, поддерживает больше БД |

## REST API, gRPC и WebSocket — как и где

| Протокол | Где используется | Почему |
| :--- | :--- | :--- |
| **REST API** | Внешние эндпоинты (регистрация, логин, посты, профиль) | Простота, кеширование, браузерная совместимость |
| **gRPC** | Внутреннее общение между микросервисами (синхронизация пользователей, события) | Быстро, контрактно, потоковая передача |
| **WebSocket** | Чаты, игровой реалтайм | Двусторонняя связь, низкая задержка |

## Ожидаемый эффект

- Единый стек для всех трёх сервисов.
- Высокая производительность.
- Удобство разработки и отладки.
- Лёгкость деплоя через Docker.
- Готовность к масштабированию.
